## FlowSim V3

[Standalone app source](FlowSimV3.html) · [Model, assumptions and test instructions](docs/flowsim-v3.md)

A browser-only recreation of the reviewed dynamic expense-coverage specification, with FLOW, deleveraging and financial freedom scenario phases. Uses synthetic defaults and makes no network requests. V3 has an independent engine; existing simulators are unchanged. Open the HTML locally to use it without deployment.

## FlowSim V2

[Open the expense coverage planner](https://rovocapitalmanagement.llc/FlowSimV2.html) · [User guide, FLOW strategy and verified monthly example](docs/flowsim-v2-guide.md) · [Model specification](docs/flowsim-v2-routing.md)

A standalone educational planner modeling target-then-reinvest distribution cash routing and monthly bill financing under explicitly selected ending checks. No account integration or financial execution.
