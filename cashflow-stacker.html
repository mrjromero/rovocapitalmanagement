The "When to Increase Stack Size" settings act as the throttle for the Cash Flow Stacking strategy...

1. Payoff Threshold

Increases stack size if LOC is paid off within a certain number of months.

2. Every Certain Number of Stacks

Increases stack size every X stacks created.

3. Every Certain Number of Months

Creates a larger stack every X months.
